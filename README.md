# Vinothkumar B — Engineering Portfolio

A modern, responsive portfolio website built with plain HTML, CSS and JavaScript.

## Open in VS Code

1. Extract this ZIP.
2. Open the `vinothkumar-portfolio` folder in VS Code.
3. Open `index.html` with Live Server, or simply open it in a browser.

## Structure

- `index.html` — complete portfolio page
- `css/style.css` — responsive design and visual system
- `js/main.js` — mobile navigation and reveal animations
- `assets/` — place project/CAD images here later

## Customize

Update contact details and project descriptions in `index.html`.
Replace/add images in `assets/` if you want project galleries.

Content is based on the supplied Vinothkumar B resume.
